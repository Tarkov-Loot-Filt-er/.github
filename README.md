## 🚀 Why Choose Tarkov Loot Filter Lens?

Tarkov loot is a time problem. The filter reduces every room to the items that matter for the current raid goal, whether that is a quest, a hideout upgrade, or pure profit. Value thresholds can be adjusted between raids without opening a menu mid-fight.

Profiles store different goals, so a quest run and a money run do not share the same highlight rules.
